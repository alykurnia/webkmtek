// Paket Edukasi KMtek (SMK & Kampus)

Buka halaman for Education →

General Kit

Paket dasar IoT untuk pembelajaran, praktikum, dan proyek siswa/mahasiswa.

Smart Garden

Paket IoT untuk memantau kelembaban tanah, suhu, dan lingkungan tanaman.

Smart Home

Paket pembelajaran sistem rumah pintar: kontrol, monitoring, dan otomasi berbasis IoT.

🅿️

Smart Parking

Simulasi sistem perparkiran cerdas: Deteksi ketersediaan slot parkir multi-spot via ultrasonik, servo palang pintu otomatis, dan display OLED.

🩺

Smart Health

Kit telemetri kesehatan: Sensor detak jantung & SpO2 MAX30102, sensor suhu tubuh non-kontak inframerah MLX90614, serta grafik web real-time.

// Solusi Hardware untuk Industri

Buka halaman for Industry →

Produk Basic Maintenance

Paket IoT untuk monitoring kondisi peralatan (getaran, suhu, jam operasi) dan perawatan preventif.

Industrial Gateway

Gateway IoT industri untuk mengumpulkan, mengolah, dan mengirimkan data secara aman.

Sensor Monitoring

Beragam sensor industri (suhu, tekanan, kelembaban, getaran, dll) untuk pemantauan operasional yang akurat.

🌦️

Mertani AWS Weather Station

Stasiun cuaca otomatis kelas industri: Pengukur curah hujan tipping bucket 0.2mm, anemometer angin 360°, solar radiasi, dan telemetri LoRaWAN/4G.

🌱

Mertani Soil Moisture Telemetry

Probe multi-kedalaman industri tahan air IP68 untuk memantau kelembapan tanah, EC salinitas, nutrisi NPK, dan suhu tanah secara kontinu di perkebunan.

🌊

Mertani Water Level & Flood

Sensor radar dan ultrasonik non-kontak untuk monitoring ketinggian air sungai, bendungan, dan saluran drainase perkebunan dengan peringatan dini banjir.
